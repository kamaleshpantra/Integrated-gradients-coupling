# Reproduction Guide: Step-by-Step Commands

**Purpose:** Exact commands to reproduce every result, figure, and table in the paper from scratch.

## Prerequisites

### 1. Python Environment
```bash
pip install torch transformers datasets scipy statsmodels pandas numpy matplotlib seaborn
```

Or use the requirements file:
```bash
pip install -r project/requirements.txt
```

### 2. Models (Download Once)
```bash

python -c "from transformers import AutoModelForSequenceClassification, AutoTokenizer; m = AutoModelForSequenceClassification.from_pretrained('distilbert-base-uncased-finetuned-sst-2-english'); m.save_pretrained('D:/models/distilbert'); t = AutoTokenizer.from_pretrained('distilbert-base-uncased-finetuned-sst-2-english'); t.save_pretrained('D:/models/distilbert')"

# MLM head (for MLM_INFILL erasure)

```

### 3. Datasets
```bash
python project/src/fetch_datasets.py
```

## Step-by-Step Reproduction

### Step 1: Run Main Experiments (M=50, 3 Seeds, 7 Erasure Schemes)

**Expected time:** ~2–4 hours on CPU, ~30 min with GPU

```powershell
cd c:\Users\91798\OneDrive\Desktop\Research
python project/src/run_revision_experiments.py
```

**Outputs:**
- `project/results/sst2_revision_seed42.csv` (8,400 rows)
- `project/results/sst2_revision_seed123.csv` (8,400 rows)
- `project/results/sst2_revision_seed999.csv` (8,400 rows)
- `project/results/sst2_revision_all450.csv` (25,200 rows — master file)
- `project/results/steps_stability.csv`
- `project/results/np_ig_ablation.csv`

### Step 2: Run Statistical Analysis

```powershell
python project/src/run_revision_analysis.py
```

**Outputs:**
- `project/results/revision_analysis_results.json` (LMM, ANOVA, worst-case tables)

### Step 3: Generate Figures

```powershell
python project/src/generate_revision_figures.py ^
  --main_csv project/results/sst2_revision_all450.csv ^
  --ablation_csv project/results/np_ig_ablation.csv ^
  --output_dir project/figures
```

**Outputs:**
- `project/figures/fig1_grid_heatmap.png` — 4×4 grid heatmap
- `project/figures/fig2_erasure_comparison.png` — Grouped erasure bar chart
- `project/figures/fig3_kendall_tau.png` — Kendall tau correlation matrix
- `project/figures/fig4_npig_ablation.png` — NP-IG temperature sweep

### Step 4: Generate Paper and Documentation

```powershell
python project/src/write_revision_paper.py ^
  --analysis_json project/results/revision_analysis_results.json ^
  --grid_csv project/results/sst2_revision_all450.csv ^
  --output_dir project/paper ^
  --draft_file project/paper_draft.md ^
  --changelog_file project/CHANGELOG.md ^
  --claims_evidence_file project/09_claims_evidence.md
```

**Outputs:**
- `project/paper/main.tex` — LaTeX paper (all numbers from JSON)
- `project/paper/main.bib` — Verified bibliography
- `project/CHANGELOG.md` — Revision changelog
- `project/09_claims_evidence.md` — Claims-evidence mapping
- `project/overleaf_paper.zip` — Ready-to-upload Overleaf package
- `overleaf_paper.zip` — Copy at project root

### Step 5: Run Tests

```powershell
python project/run_tests.py
```

Runs sanity checks: completeness axiom, determinism, random control baseline, special token exclusion.

## Verification Commands

### Verify a specific number from the paper
```python
import json
d = json.load(open("project/results/revision_analysis_results.json"))

# LMM matched coefficient
print(f"Beta_matched = {d['h1_lmm']['lmm_matched_coef']:.4f}")  # Should print 0.0342

# Uniform-IG worst-case Def 2 across all 7 schemes
print(f"Uniform Def 2 = {d['worst_case']['all_7']['UNIFORM_IG']['def2_min_of_means']:.4f}")  # Should print 0.3316

# Per-baseline MASK contrast
print(f"MASK contrast = {d['h1_lmm']['per_baseline_contrasts']['MASK']['mean_diff']:.4f}")  # Should print 0.0491
```

### Verify grid cell from raw CSV
```python
import pandas as pd
df = pd.read_csv("project/results/sst2_revision_all450.csv")
val = df[(df["method"]=="IG_MASK") & (df["scheme"]=="MASK")]["norm_comp_aopc"].mean()

```
